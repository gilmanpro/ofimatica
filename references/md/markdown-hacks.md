# Hacks y Trucos Útiles de Markdown

Para detalles completos, consulta [markdownguide.org/hacks/](https://www.markdownguide.org/hacks/).

| Necesidad | Solucion |
|-----------|----------|
| Texto centrado | `<center>texto</center>` o `<p style="text-align:center">texto</p>` |
| Color de texto | `<font color="red">texto</font>` |
| Subrayado | `<ins>texto</ins>` |
| Comentarios invisibles | `[comment]: # "texto oculto"` |
| Tabla de Contenidos | Lista de enlaces `[texto](#seccion-id)` |
| Tamaño de imagen | `<img src="img.png" width="200">` |
| Caption de imagen | `<figure><img src="..."><figcaption>Texto</figcaption></figure>` |
| Videos de YouTube | `[![alt](img.youtube.com/vi/ID/0.jpg)](https://youtu.be/ID)` |
| Enlace en nueva pestania | `<a href="url" target="_blank">texto</a>` |
| Salto de linea en tablas | `<br>` dentro de la celda |
| Listas en tablas | `<ul><li>item</li></ul>` dentro de la celda |
| Sangria (indent) | `&nbsp;&nbsp;&nbsp;&nbsp;texto` |
| Advertencias/Notas | `> :warning: **Warning:** texto` |
