# Plantilla de CV (rellenar)

Úsala como base para todo CV. Rellena los `[placeholders]`, adapta el orden de secciones según `estructura.md` y borra lo que no aplique. Regla: si un placeholder no puede rellenarse con un dato real y cuantificado, elimina esa línea.

## Encabezado
```
[Nombre Apellido]
[Titular profesional, ej.: Asistente Administrativo · 4 años en sector comercial]
[Teléfono con código de país] · [email profesional] · [Ciudad, País] · [linkedin.com/in/tu-perfil]
```

## Perfil profesional (3-6 líneas)
```
[Puesto/Especialidad] con [X] años de experiencia en [área/industria]. Especialista en [2-3 competencias clave]. [Logro destacado cuantificado: verbo de acción + métrica + contexto]. Busco aportar [valor diferencial] a [empresa/sector].
```

## Experiencia (del más reciente al más antiguo; 3-4 viñetas por puesto)
```
[Cargo] | [Empresa] | [Mes Año – Mes Año]
- [Verbo de acción en pasado] + [qué hiciste] + [contexto] + [resultado: %, €, personas, días].
- [Segunda viñeta con logro cuantificado].
- [Tercera viñeta con logro cuantificado].
```
Puestos antiguos irrelevantes: una línea con cargo, empresa y fechas, sin viñetas.

## Competencias
```
- [Hard skill 1], [Hard skill 2], [Hard skill 3] (herramientas concretas: software, metodologías, idiomas con nivel).
- [Soft skill demostrada con contexto, ej.: coordiné equipos de X personas en la implantación de ...].
```

## Formación y certificaciones
```
- [Título] | [Institución] | [Año] — solo títulos relevantes y recientes.
- [Certificación] | [Institución/plataforma] | [Año].
```

## Idiomas
```
- [Idioma]: [nivel, ej.: C1 / Avanzado / Nativo].
```

## Información adicional (opcional)
```
- [Voluntariado, proyectos, portfolio, premios, membresías — solo si aportan al puesto].
```

## Nota de entrega (incluir SIEMPRE al entregar)
- Guardar/enviar en **PDF** (salvo que la oferta pida .docx) con nombre `Nombre_Apellido_CV_Puesto.pdf`.
- Extensión: 1 página (menos de 10 años de experiencia) o máximo 2.
- Fuente clásica (Arial, Calibri, Helvetica, Georgia, Times New Roman), 10-12 pt, márgenes de 1 pulgada.
